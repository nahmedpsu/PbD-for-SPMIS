# Outreach package

Materials for proposing this work to the two communities that can carry it furthest. Nothing
here has been posted; these are ready-to-send drafts for the repository owner.

| File | Audience | Channel |
| --- | --- | --- |
| [openimis-module-proposal.md](openimis-module-proposal.md) | openIMIS developers committee and product group | openIMIS wiki "Contribution guidelines" process: a Jira ticket in the OP project, a developer-committee presentation, then a pull request to `openimis/openimis-be_py` adding the module to the reference assembly |
| [govstack-building-block-proposal.md](govstack-building-block-proposal.md) | GovStack technical committee | GovStack specification repositories on GitHub (govstack-global) and the community discussion board; proposes a "Purpose-bound Data Minimisation" capability, first as a contribution to the Consent and Registration building blocks |
| [announcement.md](announcement.md) | openIMIS community mailing list, Digital Public Goods Alliance, social protection practitioner groups | mailing list post and short-form version |

Suggested order: open the openIMIS Jira ticket and share the module proposal first (it is
concrete and testable), then the GovStack proposal, then the announcement once the first
community has had a chance to respond.
